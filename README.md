# GOAI｜酒店供应异常智能客服自主闭环

本项目面向旅行供应链中的酒店履约异常，基于 AgentTeams 构建多 Agent 智能客服闭环。系统由客户服务、异常处置、流程管理和独立核验等 Agent 协作完成订单定位、异常调查、方案生成、风险判断、受控执行与结果验证。

当前 Demo 使用合成订单和本地 Mock 业务系统，重点验证：低风险问题可在客户确认后自主闭环；高风险方案必须经过内部运营审批；所有关键动作均保留 Trace 和测试证据。
